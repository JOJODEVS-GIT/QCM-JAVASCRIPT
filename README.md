# 💻 QCM JavaScript

![Vue](https://img.shields.io/badge/Vue-3-4FC08D?logo=vuedotjs&logoColor=white)
![Vite](https://img.shields.io/badge/Vite-5-646CFF?logo=vite&logoColor=white)

## 📖 Description

Quiz interactif pour **s'entraîner en JavaScript** : 70 questions réparties en 7 thèmes, timer de 20 s par question, coloration syntaxique du code, correction expliquée, statistiques par thème et sauvegarde des meilleurs scores.

Le projet a été **migré d'un fichier HTML/CSS/JS statique vers une application Vue 3** (Composition API + Vite), en conservant **le rendu et le comportement à l'identique**. La logique (machine à états, timer, coloration, scores) a été portée en composant réactif.

## 🔗 Démo

- **Site en ligne :** https://qcm-javascript.vercel.app

## 🛠️ Technologies

- **Vue 3** (Composition API, `<script setup>`) + **Vite**
- **localStorage** (meilleurs scores)
- CSS personnalisé (thème sombre, coloration syntaxique maison)

## ✨ Fonctionnalités

- 📚 70 questions · 7 thèmes (variables, conditions, boucles, tableaux, fonctions, opérateurs, comparaisons)
- ⚡ Mode rapide (15 questions) ou complet (70 questions), questions mélangées
- ⏱️ Timer de 20 s par question (avec états d'alerte)
- 🎨 Coloration syntaxique du code
- ✅ Correction expliquée + statistiques par thème + revue détaillée
- 🏆 Meilleurs scores sauvegardés localement
